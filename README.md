# 🎉 리듬게임파티!!

카메라로 몸과 손의 움직임을 읽어 플레이하는 랜덤 리듬게임 모음 MVP입니다.

## 포함

- GitHub Pages에서 바로 배포 가능한 단일 `index.html`
- 카메라 권한/미리보기
- MediaPipe Tasks Vision 1.0.1 동적 로딩
- 손 흔들기 / 펀치 마스터 / 타겟 터치 / 좌우 피하기
- 스테이지별 랜덤 게임 선택
- 스테이지가 오를수록 BPM과 패턴 속도 증가
- PERFECT / GREAT / GOOD / MISS
- 콤보 / HP / 점수 / 최고 기록 저장
- 카메라 모델 로딩 실패 시에도 UI가 깨지지 않고 키보드 테스트 가능
- 각 미니게임 시작 전 전용 튜토리얼/조작법/판정 기준 안내

## 실행

GitHub 저장소 루트에 `index.html` 하나를 올려 GitHub Pages로 배포하면 됩니다.

로컬에서는 다음처럼 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

카메라 기능은 HTTPS 또는 localhost에서 사용하는 것을 권장합니다.

## 조작

카메라를 켠 뒤 몸/손을 움직여 플레이합니다.

카메라를 못 쓰는 환경에서는 테스트용으로 `← → / A D / Space` 키를 사용할 수 있습니다.

## 참고

MediaPipe Tasks Vision은 브라우저에서 비디오 프레임을 처리할 수 있으며 입력 영상 처리 자체는 기기에서 수행됩니다. 현재 npm의 최신 정식 버전은 1.0.1입니다.
